# Vice City Community Prototype

A responsive front-end concept for a game-native social network that combines:

- Discord-style live districts and safehouses
- Reddit-style permanent public discussions
- TikTok-style media discovery
- Game-like character identity, XP, crews, jobs and status

## Run
Open `index.html` in a browser.

## Product direction
The user creates a character, not merely an account. Every contribution strengthens identity, reputation, crew relationships, collections or progress.
